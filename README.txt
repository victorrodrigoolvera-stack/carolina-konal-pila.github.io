1) Descomprime el ZIP y abre index.html para probarlo.
2) Al tocar el botón, las flores aparecen una por una hasta formar un corazón; después cae una lluvia de corazones.
3) El contador empieza el 25/12/2025 a las 16:05.
4) Para música, coloca un archivo llamado cancion.mp3 junto a index.html. No se incluye una grabación comercial.
5) Para obtener un enlace público, sube la carpeta a GitHub Pages o Netlify. El enlace resultante se abre desde Safari/Chrome y puedes mandarlo por WhatsApp, Instagram, etc.
